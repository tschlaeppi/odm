# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use GitHub's private reporting:
**Security → Report a vulnerability** in this repository. Include the version (see the footer of the web UI or
`GET /api/system/info`), what you found and how to reproduce it. You get an answer within a few days; fixes are published as
a new release with a note in the release text.

## Supported versions

Only the latest release receives security fixes.

## How the project tries to stay trustworthy

See [docs/security.md](docs/security.md): threat model, automated checks, how to verify a release, and the known gaps.
